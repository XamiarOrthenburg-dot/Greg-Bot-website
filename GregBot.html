Welcome to Greg Bot!

Greg Bot is a powerful Discord moderation, security, anti-raid, anti-spam, and server protection bot built to help keep your community secure and manageable.

🛡️ Anti-Raid

Detect and respond to suspicious joining activity and potential raid behavior.

🚫 Anti-Spam

Help detect excessive messaging and unwanted spam activity.

🔒 Server Security

Tools for lockdowns, channel controls, verification, and server security checks.

🧠 Threat Intelligence

Examine server threats, security risks, and other important monitoring information.

All Commands

Explore everything Greg Bot has available for your Discord server.

🛡️ Security & Anti-Raid

/deep-scan

Searches through a user's profile to detect potential risks such as raider or nuker activity.

/prune-raid

Selects how many minutes back to check for users who joined and kicks users within that timeframe.

/security-check

Checks server security risks and recommends possible security changes.

/setup-verification

Sets up server verification.

/threat-intel

Displays server threat intelligence and other information for security examination.

/threat-level

Allows administrators to alter the server's security level.

🔒 Server Control

/channel lock

Locks the selected channel.

/freeze

Freezes all channels.

/lockdown

Pauses server invites.

/unlockdown

Resumes server invites.

/slowmode-all

Activates slowmode across the server using a time selected by an administrator.

🔨 Moderation

/discipline-list

Displays current timeouts and bans.

/infractions

Examines the selected user's current infractions.

/untimeout

Immediately lifts the isolation timeout from a user.

/warn

Warns the selected user.

⚙️ Automated Systems

/automated-systems

Displays a complete list of the currently active automated systems.

/filter-curses

Turns the profanity filter on or off and allows administrators to adjust its intensity.

📊 Monitoring & Information

/system-hud

Displays a system monitoring terminal.

/prefix-commands

Displays all available "!" prefix commands.

📢 Utility

/announce

Creates an embedded announcement with a selectable color, title heading, and description.
